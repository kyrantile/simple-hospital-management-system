# Hospital Management System

A quick, simple web app for managing:
- patients
- doctors
- appointments

## Features
- Add patient records
- Add doctor records
- Book appointments
- Delete records
- Dashboard summary cards
- Data saved in browser localStorage

## Run it
Because this is a static app, you can launch it with a simple local web server:

```bash
cd /path/to/project
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files
- `index.html` — app structure
- `styles.css` — styling
- `script.js` — app logic
